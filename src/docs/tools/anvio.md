Anvi'o is a multi-omics analysis and visualization platform that, in iVirus workflows, is used for read-coverage visualization of viral contigs, viral pangenomics, and interactive genome browsing — providing a unified interface for integrating assembly, annotation, and abundance data.

## Install

Anvi'o requires an isolated conda environment due to its complex dependency stack.

```bash
conda create -n anvio-8 python=3.10 -y
conda activate anvio-8
conda install -c conda-forge -c bioconda anvio
```

Verify the installation:

```bash
anvi-self-test --suite mini
```

## Basic usage

Building and viewing a contigs database with annotation:

```bash
# Build contigs database
anvi-gen-contigs-database -f contigs.fa -o contigs.db -n "My viral metagenome"

# Run default HMMs (including viral HMMs if available)
anvi-run-hmms -c contigs.db -T 16

# Profile a BAM file (read mapping results)
anvi-profile -i mapping.bam -c contigs.db -o profile_dir/

# Launch interactive interface
anvi-interactive -c contigs.db -p profile_dir/PROFILE.db
```

For viral pangenomics across multiple samples or isolates, see `anvi-gen-genomes-storage` and `anvi-pan-genome`.

## Key flags

| Flag | Description |
|------|-------------|
| `-c` | Path to the contigs database (`.db`) |
| `-p` | Path to the profile database (`PROFILE.db`) |
| `-f` | Input FASTA file (for `anvi-gen-contigs-database`) |
| `-T` | Number of threads |
| `--server-only` | Start the web server without opening a browser (for remote/HPC use) |
| `--ip-address` / `--port-number` | Bind address and port for remote access (default: localhost:8080) |

## Output

- **Interactive browser at `localhost:8080`** — the primary interface; displays contig coverage, GC content, annotation layers, and binning results as a circular or rectangular dendrogram.
- **`SUMMARY/`** directory (after `anvi-summarize`) — per-bin statistics, gene calls, and coverage tables exported to TSV/FASTA for downstream use.
- **Pangenome display** — gene cluster presence/absence matrix across genomes, useful for comparing viral populations across samples.

## In the iVirus workflow

Anvi'o is used in the Visualization step and also integrates with Abundance and Ecology analyses. Contigs from [SPAdes](/docs/tools/spades/) or [MEGAHIT](/docs/tools/megahit/) are loaded into a contigs database; read mapping BAM files (generated by tools such as Bowtie2 or BWA) are profiled to display per-contig coverage. Viral contigs identified by [VIBRANT](/docs/tools/vibrant/) or [VirSorter](/docs/tools/virsorter/) can be refined interactively as bins. For network-based taxonomy, [Cytoscape](/docs/tools/cytoscape/) handles [vConTACT2](/docs/tools/vcontact2/) output.
