Taxonomy

Assign taxonomic labels to viral sequences using gene-sharing networks or k-mer similarity.

Tool Description Platforms Links Reference
vConTACT2 Assigns taxonomy to uncultivated prokaryotic viruses using gene-sharing networks benchmarked against the ICTV classification — the community standard for phage taxonomy. HPC CyVerse Docs · Official Bin Jang et al., Nat Biotechnol (2019)
vConTACT2-Gene2Genome Preprocessing step for vConTACT2 — converts protein FASTA sequences into the gene-to-genome mapping file required by the classifier. HPC CyVerse KBase Docs coming soon · Official Bin Jang et al., Nat Biotechnol (2019)
CAT/BAT Taxonomic classification of assembled contigs (CAT) and metagenome-assembled bins (BAT) using diamond-based alignment and a last common ancestor approach. HPC Docs · Official von Meijenfeldt et al., Genome Biol (2019)
VIRIDIC Calculates intergenomic similarity between phage genomes using BLAST-based nucleotide comparisons, enabling genus- and species-level demarcation following ICTV criteria. HPC Docs · Official Moraru et al., Viruses (2020)
