Host Prediction

Predict the prokaryotic hosts of viral sequences using sequence- or signal-based methods.

Predicting the prokaryotic hosts of environmental viruses is essential for understanding their ecological roles, yet most viruses lack cultivated hosts. Host prediction tools exploit signals such as CRISPR spacer matches, sequence composition similarity, and co-occurrence patterns to infer the likely host genus. No single method is perfect, so integrated approaches that combine multiple signals — such as iPHoP — generally outperform single-method tools.
Tool Description Platforms Links Reference
WIsH Predicts prokaryotic hosts of viruses from metagenomic data using a homogeneous Markov chain model trained on genome composition. HPC Docs · Official Galiez et al., Bioinformatics (2017)
HostPhinder Predicts phage host range based on k-mer similarity between phage and host genomes. CyVerse Docs · Official Villarroel et al., Viruses (2016)
iPHoP Integrated machine learning framework that combines multiple host-prediction signals (CRISPR spacers, k-mer similarity, gene-sharing) for high-accuracy host genus prediction of archaeal and bacterial viruses. HPC Docs · Official Roux et al., PLOS Biology (2023)
