Visualization

Explore and visualize viral networks, community structure, and genomic context.

Stage 10 of the Viral Metagenome Workflow. Click Visualize & Explore for the walkthrough, or a neighboring stage to browse its tools.

Visualization tools help make sense of complex viral datasets by rendering gene-sharing networks, genome arrangements, and community structure in interactive or publication-quality graphics. Network-based tools like Cytoscape are commonly used to explore vConTACT2 output, while platforms like Anvi'o provide a unified environment for inspecting read coverage, pangenomics, and genome annotations in a single interactive browser.
Tool Description Platforms Links Reference
Cytoscape Network visualization and analysis tool widely used to explore and render gene-sharing networks generated by vConTACT2. CyVerse Desktop Docs · Official Shannon et al., Genome Res (2003)
Anvi'o Advanced multi-omics analysis and visualization platform used for pangenomics, metagenome-assembled genome inspection, and viral community profiling. HPC Docs · Official Eren et al., PeerJ (2015)
