Viral Identification

Detect viral sequences from metagenomic assemblies using diverse detection strategies.

Identifying viral sequences from metagenomic assemblies remains a major challenge in the field of viral ecology. A variety of approaches have been proposed, each dependent on the source of data and the underlying biological question. Tools range from signal-based approaches that look for hallmark viral genes to machine learning models trained on sequence composition. We recommend running multiple identification tools and using CheckV to assess the quality and completeness of predicted viral genomes before proceeding to annotation.
Tool Description Platforms Links Reference
VirSorter2 Multi-classifier, expert-guided approach for detecting diverse DNA and RNA viruses — the current recommended successor to VirSorter. HPC CyVerse Docs coming soon · Official Guo et al., Microbiome (2021)
VIBRANT Automated recovery, annotation, and curation of viral genomes from metagenomes using protein profiles and machine learning. HPC CyVerse Docs · Official Kieft et al., Microbiome (2020)
DeepVirFinder Identifies viral sequences in metagenomes using a deep learning model trained on sequence composition — works without requiring gene predictions. HPC CyVerse Docs coming soon · Official Ren et al., Quantitative Biology (2020)
MARVEL Predicts bacteriophage sequences within metagenomic bins using random forest classification on genomic features. HPC CyVerse KBase Docs coming soon · Official Amgarten et al., Front Genet (2018)
VirSorter Original signal-based tool for mining viral signatures from microbial genomic data. Superseded by VirSorter2 for most use cases. HPC CyVerse Docs · Official Roux et al., PeerJ (2015)
CheckV Assesses quality and completeness of metagenome-assembled viral genomes, removes host contamination from integrated proviruses, and classifies sequences as complete, high-, medium-, or low-quality draft. HPC Docs · Official Nayfach et al., Nature Biotechnology (2021)
PropagAtE Estimates whether an integrated prophage is in lytic (actively replicating) or lysogenic (dormant) state by comparing read coverage of the prophage region to that of the host chromosome. HPC Docs · Official Kieft & Anantharaman, bioRxiv (2021)
